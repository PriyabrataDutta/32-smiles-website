## 📌 Executive Summary

This platform is a ground-up reimagination of [32 Smiles Dental Clinics](https://32smilesdentalclinics.com/), Bangalore's premier multispeciality dental network established in 2005. Engineered to bridge the gap between high-end private aesthetic dentistry and scalable digital healthcare infrastructure, the application delivers **40 statically pre-rendered routes** with instant page transitions, accessible WCAG 2.2 compliant contrast, and mobile-first ergonomics.

---

## ✨ Key Platform Features

### 1. Luxury Medical Design System
* **Curated Palette**: Soft Warm Cream (`#FAF4EA`), Gold Foil (`#D9A93B`), Warm Bronze (`#795900`), and Deep Espresso (`#2B2420`).
* **Editorial Typography**: Styled using `Playfair Display` for high-trust headings and `Inter` for clean clinical readability.
* **Micro-Interactions**: Fluid card elevation hovers, shimmer badges, and mobile-sticky action drawers.

### 2. Full-Width Clinical Mega Menu
* Spans the full container width (`max-w-7xl` / `1280px`).
* Organizes **all 14 dental procedures** across 4 logical clinical pillars:
  * **Orthodontics & Aligners**
  * **Implants & Oral Surgery**
  * **Cosmetic & Smile Makeover**
  * **Preventive & Periodontics**
* Integrated **Patient Action Panel** featuring 3D iTero optical scan preview, 0% EMI financing rates, and direct WhatsApp doctor contact.

### 3. Dedicated Bangalore Clinic Directory (9 Branches)
* Real-time search by neighborhood, transit landmark, or metro station.
* Geographic sub-filters: *East Bangalore, South Bangalore, Tech Corridor / Outer Ring Road*.
* Branch-specific pages featuring transit connectivity, resident doctor schedules, parking assistance, and Google Maps navigation.

### 4. Interactive Patient Portals & Clinical Calculators
* **Interactive Touch/Drag Before-and-After Slider**: Allows prospective patients to slide across real clinical before/after results for severe crowding, gap closure, and full-mouth rehabilitations.
* **Instant 0% Dental EMI Calculator**: Real-time monthly installment estimator across 3, 6, 9, 12, and 24-month tenures with preset procedure costs.
* **15-Minute Guaranteed Callback Form**: Pre-populated with branch and treatment selections, with built-in 10-digit Indian mobile validation and direct WhatsApp integration.
* **Dental Tourism Concierge**: Tailored multi-day travel itineraries, complimentary Kempegowda International Airport transfers, and cost-comparison matrices for international patients and NRIs.

## 🛠️ Technology Stack

| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| **Framework** | Next.js 16.4.3 (App Router) | Static Site Generation (SSG), Partial Prerendering (PPR), Dynamic Metadata. |
| **Build Engine** | Turbopack | Sub-second fast HMR, optimized production asset bundling. |
| **Frontend Library** | React 19.0.0 | Concurrent React, server and client component architecture. |
| **Language** | TypeScript 5.0 | End-to-end type safety across datasets, clinical models, and custom hooks. |
| **Styling** | Tailwind CSS v4 & CSS3 Tokens | Utility-first styling with custom design tokens, animations, and fluid typography. |
| **Icons** | Lucide React | Modern, lightweight, accessible SVG healthcare iconography. |
| **Fonts** | Google Fonts (`next/font`) | Zero layout-shift self-hosted `Playfair Display` and `Inter`. |

## 🚀 Getting Started

### Prerequisites
- **Node.js**: `v18.18.0` or higher
- **Package Manager**: `npm` (v9+) or `yarn` / `pnpm`

### Installation & Local Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/PriyabrataDutta/32-smiles-website.git
   cd 32-smiles-website
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start the Development Server**:
   ```bash
   npm run dev
   ```

4. **View in Browser**:
   Open [http://localhost:3000](http://localhost:3000) to inspect the live application.
